# BRIEF — Better 3D Periodic Table

**Goal:** Build a MUCH better version of Ryan Sael's interactive 3D periodic table (https://sael.net/periodic-table). moony's ask: "replicate this but make it way much better."

**Form:** One self-contained three.js web page. All shapes made in code, no external assets, real citable data. Works on desktop and mobile.

**Audience:** Curious students — including moony's math-gifted 8-year-old son — and adults; plus the general web audience (the X post had ~90k views).

**Done criteria (summary; full list in SPEC.md):**
- Every weakness of the original (see ref/VIDEO_NOTES.md) is beaten, or consciously deferred in the SPEC's "later" list.
- Real orbital shapes, real per-element crystal lattices, search/filters/legend, trends + compare, rich data sheet, quiz mode, Vietnamese + English.
- Smooth: target FPS on desktop and mobile with quality tiers.
- Data checked against sources; screenshots checked.
- moony approves SPEC.md before any app code is written.
