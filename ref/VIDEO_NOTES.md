# Ryan Sael 3D periodic table — video analysis (28s demo, x.com/RyanSael/status/2114706108317372821, site sael.net/periodic-table)
Views: Table (3D columns, height = Ionisation/Size/Pull/Melting/Density, desk diorama w/ DOF), Atom (nucleus spheres + glowing electron point-cloud shells, 3D callout labels, pm radii, emission spectrum panel), Sample (glass cube particle sim, thermometer, temperature slider: solid->liquid->gas), Demo (scripted dioramas: alkali+water, flame tests, neon tubes, Kr spectrum, Mg burning, Bi crystals, iron filings+magnet, diamond vs graphite, U decay).
Transitions: columns animate heights; click column -> camera dives into atom view; "each click adds a proton".
UI: top-left data panel (name, symbol, Z, weight, mp/bp, description, legend); top-right controls (HEIGHT, ELEMENT arrows, VIEW, TEMPERATURE). Hover tooltip w/ value. Orbit camera. PBR + heavy bloom.
Weaknesses: legend misses reactive nonmetals; spherical shells not real s/p/d/f orbitals; sample sim is generic cubic grid (not real BCC/FCC/HCP lattice); no search; shallow data; small 3D labels; (check) no learning/quiz mode, mobile.
