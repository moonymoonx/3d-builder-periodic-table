# PLAN — Better 3D Periodic Table v1 (build plan for the approved SPEC.md)

SPEC.md is authoritative. This file says *how* and *in what order*; LOG.md says what actually happened.

## File layout
```
data/raw/<source>/…        raw downloads, untouched (+ data/raw/MANIFEST.json: url, accessed, licence, sha256, bytes)
data/curated/*.json        small hand-entered tables (flagged source "curated…", each with reason)
data/elements.json         compiled dataset (generated by tools/build-data.mjs, committed for review)
tools/fetch.mjs            downloads every raw source, writes MANIFEST.json, logs failures
tools/build-data.mjs       raw -> data/elements.json (per-value source keys, units, nulls with reasons)
tools/validate.mjs         data + physics validator (exit 1 on any failure)
tools/build.mjs            src/ + three.module.min.js + data -> ./index.html (single file, <= 2 MB)
tools/shots.mjs            optional playwright screenshots (playwright lives OUTSIDE repo: ../tools-env)
src/physics/*.js           pure maths shared by app + node tests (orbitals, lattices, colour, units)
src/app/*.js               UI + three.js views
src/i18n/*.js              EN / VI strings
src/styles.css, src/index.html (template)
tests/*.test.mjs           node --test suites (data, orbitals, lattices, i18n/search)
index.html                 BUILT single-file app (committed so it opens offline)
screenshots/               scripted screenshots
```

## Data pipeline (real sources only; nothing typed from memory is presented as sourced)
| Data | Primary source (fetched) | Cross-check |
|---|---|---|
| names, symbol, category (GroupBlock), state, mp/bp, density, EN, EA, ox. states, year | PubChem Periodic Table JSON | Wikipedia element infoboxes, mendeleev DB (CRC values) |
| standard atomic weight | CIAAW abridged table (+ full table for intervals) | PubChem |
| ground configuration, ground level, 1st IE | NIST ASD ionization-energy query (neutral atoms) | PubChem |
| emission lines 380–750 nm (air), neutral atoms | NIST ASD lines query, one per element | golden Na D |
| crystal structure, Pearson symbol, lattice constants, Fe allotropes | Wikipedia `Template:Infobox <element>` wikitext (cites Arblaster 2018 etc.) | mendeleev `lattice_*` |
| internal atomic positions for non-trivial structures | COD CIF files (fetched by id) | — |
| phase transitions, sublimation, Sn/Fe transitions | mendeleev `phasetransitions` (CRC 2016) + Wikipedia infobox | PubChem mp/bp |
| covalent radius (Cordero 2008), vdW radius (Alvarez 2013), Clementi–Raimondi screening, crustal abundance (CRC) | mendeleev v1.3.0 DB (MIT, per-column citation keys) | PubChem |
| isotopes, half-lives, charge radii | IAEA LiveChart API (NUBASE2020/ENSDF) | — |
| VI traditional names | Wikidata vi labels (CC0) | vi.wikipedia |
| VI textbook (GDPT-2018) names | IUPAC English names per GDPT-2018 convention — flagged for moony to check | — |

Every value in the JSON is `[value, sourceKey, note?]`; a missing value is `[null, "none", reason]`. Units live in one field table. Predicted/estimated values carry a flag so the UI can hatch them.

## Milestones and acceptance checks (validator runs at every milestone; commit + LOG.md + DECISIONS.md after each)
- **M1 data + validator** — fetch.mjs/build-data.mjs/validate.mjs; MANIFEST complete; validator passes: 118 unique Z, units, a source on every value, one category each, golden values (Ga mp 29.76 °C, α-Fe a = 286.65 pm, Cr [Ar]3d⁵4s¹, Na D 589.0/589.6 nm, H IE 13.598 eV), orbital maths for all 19 occupied subshells (normalised; n−l−1 radial nodes; l angular nodes); cross-source report (20 random elements × 5 fields).
- **M2 table** — 18/32/helix layouts with animated morph; height = property (log option), ghost (no data) and hatched (predicted) columns; search (EN/VI accent-insensitive, symbol, Z); filters (category, block, group, period, state at T, natural/synthetic); full legend; data sheet (~25 sourced fields, tap value → source); screen-space labels ≥ 14 px with overlap culling. Check: built page loads with no console errors; screenshots.
- **M3 atom** — hydrogen-like ψ(n,l,m) with Z_eff (Clementi–Raimondi, else Slater): phase-coloured point clouds for every occupied subshell, 90 % isosurfaces (Medium+), single orbital ↔ total density, nucleus with its true enlargement factor, add-a-proton stepper (flags Madelung exceptions), NIST lines strip (tap → λ) + approximate glow colour. Check: orbital tests; screenshots of H, C, Fe, Au, U.
- **M4 sample** — measured lattice per element (prototype + measured a/b/c, positions from symmetry or COD), temperature slider: Lindemann vibration, melt/boil at real 1-atm points, sublimation (C, As), He (no solid at 1 atm), Fe α→γ→δ, graphite ↔ diamond, gas speed √(3RT/M); honest card for the rest. Check: lattice unit tests (nearest-neighbour distance vs a), screenshots.
- **M5 trends + compare** — property-vs-Z chart linked to table, one-line "why"; two elements side by side at one scale with ratio bars + plain sentences.
- **M6 quiz** — Socratic, one question at a time, tap scene or choice, miss → smaller guiding question + camera flies to evidence; skill map 0–5 × 6 skills in localStorage; hand-written + data-generated questions (answers computed from the JSON).
- **M7 polish** — EN/VI everywhere, Low/Med/High auto + manual, render-on-demand, phone layout, keyboard, colour-blind-safe palette, reduced motion, shareable URL hash, Credits panel, FPS meter (median + p95).
